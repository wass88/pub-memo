スマホでバイブコーディングして寝れなくなる (tailscale+ttyd+zellij+ntfy)

作成日: 2026-01-17
バイブコーディングしてますか？
ターミナルと向き合うのめんどくさいですよね。 スマホでごろごろできる環境を整えました

mac側の準備

brew update
brew install --cask tailscale
# ttyd（Web 経由で TTY を提供）
brew install ttyd
# Zellij（Rust 製ターミナルマルチプレクサ）
brew install zellij
あとは使えるコーディングエージェントを準備して下さい。

Android側の準備

Tailscalehttps://play.google.com/store/apps/details?id=com.tailscale.ipn をセットアップして、macにつながるようにしましょう。
あと、快適にキー入力するためにUnexpected Keyboardが良かったです。https://play.google.com/store/apps/details?id=juloo.keyboard2
完了通知はntfyでもらいましょう。https://play.google.com/store/apps/details?hl=ja&id=io.heckel.ntfy&utm_source=chatgpt.com
ntfyで処理完了したらお知らせするようにして、とコーディングエージェントに言うと、よしなにしてくれます。

ttydを起動する

while : ; do ttyd -Wp 18080 zellij a ; sleep 5 ; done
tailscaleのmacアドレス:18080にアクセスすればつながります。
気の済むまで話し続けましょう。
